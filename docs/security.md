# 安全模型

Wayfinder 把飞书消息、模型输出、日志文本、容器名和系统命令输出都视为不可信输入。

## 已实施控制

- 飞书用户角色采用显式 allowlist，支持 `viewer`、`operator`、`admin`。
- 指定群聊才允许使用，且群消息必须明确 @ 机器人。
- 工具注册表仅包含五个只读名称；未知工具和所有动作工具默认拒绝。
- 工具参数使用 `additionalProperties: false` 的空对象 Schema。
- 子进程不使用 Shell，不接受模型生成的命令或参数。
- 命令有超时、输出上限、最小环境和并发/排队上限。
- 工具输出在返回模型前递归截断并按敏感字段名脱敏。
- 入站事件 ID 持久化去重；审计记录请求、身份摘要、会话、工具、参数摘要、时间、状态和错误类型。
- 飞书凭证、模型密钥、业务数据库和会话数据库均被 Git 忽略。
- 健康接口只允许绑定回环地址。

## 运维边界

服务以独立 `wayfinder` 用户运行，不以 root 常驻。不要将该用户加入 `docker` 组，也不要挂载 Docker socket；两者近似授予主机 root 权限。当前 Docker 状态工具在没有安全只读代理时返回不可用，这是预期的安全降级。

任何未来动作必须经过服务端一次性审批票据，并在执行前重新验证用户、会话、角色、工具、规范化参数和过期时间。网络动作在本地 watchdog、状态验证和自动回滚完成测试前不得注册。

## 凭证处理

生产环境文件建议位于 `/etc/wayfinder/wayfinder.env`，归属 `root:wayfinder`，权限 `0640`。日志不应记录环境变量值、令牌、完整敏感路径或原始命令输出。凭证泄露后应在飞书和模型供应商侧轮换，而不是只修改本地文件。

当前 Pi 会话会持久化用户消息、模型回复和结构化 NAS 结果，SQLite 内容没有应用层静态加密，主要依赖独立账户、`0700/0600` 权限和宿主机磁盘保护。生产启用前必须确定会话、审计、入站事件和告警的保留/删除周期。

当前模型适配器使用 OpenAI 或 Anthropic 云 API；启用后，对话内容以及模型为回答所需的 SSID、IP、主机名、挂载点或容器元数据可能离开 NAS。管理员应先确认数据出境政策和用户同意；若要求全本地推理，本代码基线尚不满足，必须先增加并验证本地模型适配器。
